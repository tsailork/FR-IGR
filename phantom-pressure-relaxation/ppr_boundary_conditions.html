Phantom Pressure Regularization (PPR)

Comprehensive Theory & Implementation Guide for General 2D/3D Boundary Conditions

1. The Theoretical Boundary Failure: "The Wall Lag Trap"

In high-order spatial schemes (e.g., Flux Reconstruction, Discontinuous Galerkin), Phantom Pressure Regularization (PPR) regularizes shock waves by introducing an advected scalar state $S = \rho P_{phan}$. The regularized pressure $P_{reg}$ used in interface momentum flux evaluations is defined as:

$$P_{reg} = P_{phys} + \theta (P_{phys} - P_{phan})$$

where $P_{phys}$ is the thermodynamic pressure, $P_{phan} = S/\rho$ is the phantom pressure, and $\theta > 0$ is a tuning parameter.

The Physics of Boundary Blowup

When strong shocks impact or move along solid walls in 2D and 3D, naive ghost-state formulations cause catastrophic numerical blowups. The physical and numerical mechanisms behind this instability are:

  1. Kinematic Advection Lock: At an inviscid wall boundary, the normal flow velocity is strictly zero ($\mathbf{u} \cdot \mathbf{n} = 0$). Consequently, the advective normal flux of the phantom variable across the wall is zero ($S \mathbf{u} \cdot \mathbf{n} = 0$). Phantom pressure cannot be transported across or along the boundary by fluid convection.
  2. Thermodynamic Reflection Lag: During shock reflection at a wall, the physical pressure $P_{phys}$ jumps instantaneously. However, $P_{phan}$ at the boundary interface relies solely on the pointwise relaxation source term $\frac{\rho}{\tau}(P_{phys} - P_{phan})$ to adjust. Because the relaxation time $\tau$ is finite, $P_{phan}$ lags severely behind $P_{phys}$.
  3. Unphysical Force Spike: Because $P_{phys} \gg P_{phan}$ during shock impact, the regularized pressure $P_{reg}$ at the wall face spikes to an unphysically massive value ($P_{reg} \gg P_{phys, shock}$).
  4. Feedback Loop & Breakdown: This artificial pressure spike exerts a massive normal force vector pushing away from the wall face into adjacent interior elements. In subsequent Runge-Kutta sub-stages, this force drives an unphysical acoustic expansion wave, triggering velocity divergence shocks near the wall that amplify $P_{reg}$ further until the solver crashes ($\text{NaN}$).
Fundamental Principle: Hyperbolic bulk viscosity is designed to damp volumetric compression inside the fluid domain ($\nabla \cdot \mathbf{u} < 0$). It must never penalize the kinematic boundary constraint ($\mathbf{u} \cdot \mathbf{n} = 0$).

2. Mathematical Formulation: The Wall-Equilibrated Ghost State (WE-BC)

To prevent boundary blowups, we construct a Wall-Equilibrated (WE) Ghost State ($\mathbf{U}^+$) for the interface Riemann solver. This state forces the face-averaged regularized pressure $P_{reg, face}$ at solid boundaries to equal the physical thermodynamic pressure $P_{phys}^-$, while allowing full regularized bulk-viscosity damping at interior element nodes.

General 2D/3D Kinematic Kinematics

Let $\mathbf{n} = [n_x, n_y, n_z]^T$ be the unit outward normal vector at a boundary face, and $\mathbf{U}^- = [\rho^-, \rho^- u_x^-, \rho^- u_y^-, \rho^- u_z^-, E^-, S^-]^T$ be the interior state extrapolated to the interface face.

The normal velocity component $u_n^-$ and vector velocity $\mathbf{u}^-$ are:

$$u_n^- = \mathbf{u}^- \cdot \mathbf{n} = u_x^- n_x + u_y^- n_y + u_z^- n_z$$ $$\mathbf{u}^+ = \mathbf{u}^- - 2 u_n^- \mathbf{n}$$

Mathematical Proof of Pressure Equilibration

To enforce $P_{reg, face} \equiv P_{phys}^-$, we define the ghost phantom state $S^+$ as:

$$S^+ = 2 \rho^- P_{phys}^- - S^-$$

Evaluating the face-averaged phantom pressure $P_{phan, face}$ across the boundary interface yields:

$$P_{phan, face} = \frac{1}{2}\left(P_{phan}^- + P_{phan}^+\right) = \frac{1}{2}\left(\frac{S^-}{\rho^-} + \frac{S^+}{\rho^-}\right) = \frac{1}{2}\left(\frac{S^- + 2\rho^- P_{phys}^- - S^-}{\rho^-}\right) = P_{phys}^-$$

Substituting $P_{phan, face}$ into the regularized pressure expression at the boundary face gives:

$$P_{reg, face} = P_{phys}^- + \theta \left( P_{phys}^- - P_{phan, face} \right) = P_{phys}^- + \theta (0) \equiv P_{phys}^-$$

This guarantees that the momentum reaction force exerted by the boundary face is strictly bounded by the physical thermodynamic pressure $P_{phys}^-$.

3. General 2D/3D Boundary Condition Specification

Below is the mathematical specification for constructing the ghost state vector $\mathbf{U}^+ = [\rho^+, \rho^+\mathbf{u}^+, E^+, S^+]^T$ across all standard boundary types in 2D and 3D solvers.

1. Inviscid Solid Wall (Slip Boundary)

Reflects normal velocity, preserves density and thermodynamic pressure, and applies wall-equilibration to the phantom state.

$$\rho^+ = \rho^-, \quad \mathbf{u}^+ = \mathbf{u}^- - 2(\mathbf{u}^- \cdot \mathbf{n})\mathbf{n}, \quad P_{phys}^+ = P_{phys}^-$$ $$E^+ = \frac{P_{phys}^-}{\gamma - 1} + \frac{1}{2}\rho^- \|\mathbf{u}^+\|^2, \quad S^+ = 2 \rho^- P_{phys}^- - S^-$$

2. Viscous Solid Wall (No-Slip Boundary)

Enforces zero velocity at the wall ($\mathbf{u}_{wall} = \mathbf{0}$) and zero normal pressure gradient ($\nabla P_{phys} \cdot \mathbf{n} = 0$).

$$\rho^+ = \rho^-, \quad \mathbf{u}^+ = -\mathbf{u}^-, \quad P_{phys}^+ = P_{phys}^-$$ $$E^+ = \frac{P_{phys}^-}{\gamma - 1} + \frac{1}{2}\rho^- \|\mathbf{u}^+\|^2, \quad S^+ = 2 \rho^- P_{phys}^- - S^-$$

3. Supersonic Inflow

All characteristics enter the domain. Set all state variables directly to the free-stream Dirichlet conditions $[\rho_\infty, \mathbf{u}_\infty, P_\infty]^T$:

$$\rho^+ = \rho_\infty, \quad \mathbf{u}^+ = \mathbf{u}_\infty, \quad E^+ = \frac{P_\infty}{\gamma - 1} + \frac{1}{2}\rho_\infty \|\mathbf{u}_\infty\|^2, \quad S^+ = \rho_\infty P_\infty$$

4. Supersonic Outflow

All characteristics exit the domain. Copy the interior state directly:

$$\mathbf{U}^+ = \mathbf{U}^-$$

5. Subsonic Outflow

Prescribe target static exit pressure $P_{out}$. Extrapolate density, velocity, and equilibrate the ghost phantom state to $P_{out}$:

$$\rho^+ = \rho^-, \quad \mathbf{u}^+ = \mathbf{u}^-, \quad P_{phys}^+ = 2 P_{out} - P_{phys}^-$$ $$E^+ = \frac{P_{phys}^+}{\gamma - 1} + \frac{1}{2}\rho^+ \|\mathbf{u}^+\|^2, \quad S^+ = 2 \rho^- P_{out} - S^-$$

6. Subsonic Inflow

Prescribe free-stream density $\rho_{in}$, velocity $\mathbf{u}_{in}$, and static pressure $P_{in}$.

$$\rho^+ = \rho_{in}, \quad \mathbf{u}^+ = \mathbf{u}_{in}, \quad E^+ = \frac{P_{in}}{\gamma - 1} + \frac{1}{2}\rho_{in} \|\mathbf{u}_{in}\|^2, \quad S^+ = \rho_{in} P_{in}$$

4. Production Python Implementation (2D & 3D Compatible)

The following routine implements general boundary ghost state construction and evaluates the boundary normal flux using a PPR-compatible Rusanov interface solver. It handles both 2D (with $w=0, n_z=0$) and 3D solvers.

import numpy as np def compute_ppr_boundary_flux(U_int, normal, bc_type, bc_params, theta, gamma): """ Evaluates generalized 2D/3D numerical boundary fluxes for PPR/HBV solvers. Parameters: ----------- U_int : ndarray shape (6,) -> [rho, rhou, rhov, rhow, E, S] (Interior State) normal : ndarray shape (3,) -> Unit outward normal vector [nx, ny, nz] bc_type : str -> 'SLIP_WALL', 'NO_SLIP_WALL', 'SUPERSONIC_INFLOW', 'SUPERSONIC_OUTFLOW', 'SUBSONIC_OUTFLOW', 'SUBSONIC_INFLOW' bc_params : dict -> Boundary values (e.g., {'P_out': 101325.0, 'rho_in': 1.225, ...}) theta : float -> PPR regularizing parameter gamma : float -> Specific heat ratio """ rho_in = U_int[0] inv_rho = 1.0 / rho_in u_in = U_int[1] * inv_rho v_in = U_int[2] * inv_rho w_in = U_int[3] * inv_rho ke_in = 0.5 * rho_in * (u_in**2 + v_in**2 + w_in**2) P_phys_in = (gamma - 1.0) * (U_int[4] - ke_in) S_in = U_int[5] U_ghost = np.zeros(6) # ========================================================================= # 1. GHOST STATE CONSTRUCTION # ========================================================================= if bc_type == 'SLIP_WALL': un = u_in * normal[0] + v_in * normal[1] + w_in * normal[2] u_g = u_in - 2.0 * un * normal[0] v_g = v_in - 2.0 * un * normal[1] w_g = w_in - 2.0 * un * normal[2] U_ghost[0] = rho_in U_ghost[1] = rho_in * u_g U_ghost[2] = rho_in * v_g U_ghost[3] = rho_in * w_g U_ghost[4] = P_phys_in / (gamma - 1.0) + 0.5 * rho_in * (u_g**2 + v_g**2 + w_g**2) U_ghost[5] = 2.0 * rho_in * P_phys_in - S_in # WE-BC Formulation elif bc_type == 'NO_SLIP_WALL': U_ghost[0] = rho_in U_ghost[1] = -U_int[1] U_ghost[2] = -U_int[2] U_ghost[3] = -U_int[3] U_ghost[4] = P_phys_in / (gamma - 1.0) + 0.5 * rho_in * (u_in**2 + v_in**2 + w_in**2) U_ghost[5] = 2.0 * rho_in * P_phys_in - S_in # WE-BC Formulation elif bc_type == 'SUPERSONIC_OUTFLOW': U_ghost = U_int.copy() elif bc_type == 'SUBSONIC_OUTFLOW': P_out = bc_params['P_out'] P_g = 2.0 * P_out - P_phys_in U_ghost[0] = rho_in U_ghost[1] = U_int[1] U_ghost[2] = U_int[2] U_ghost[3] = U_int[3] U_ghost[4] = P_g / (gamma - 1.0) + ke_in U_ghost[5] = 2.0 * rho_in * P_out - S_in # Target P_out at face elif bc_type == 'SUPERSONIC_INFLOW': rho_inf = bc_params['rho'] u_inf, v_inf, w_inf = bc_params['u'], bc_params['v'], bc_params['w'] P_inf = bc_params['P'] ke_inf = 0.5 * rho_inf * (u_inf**2 + v_inf**2 + w_inf**2) U_ghost[0] = rho_inf U_ghost[1] = rho_inf * u_inf U_ghost[2] = rho_inf * v_inf U_ghost[3] = rho_inf * w_inf U_ghost[4] = P_inf / (gamma - 1.0) + ke_inf U_ghost[5] = rho_inf * P_inf # ========================================================================= # 2. RIEMANN INTERFACE FLUX EVALUATION (PPR-Rusanov) # ========================================================================= return compute_ppr_rusanov_interface_flux(U_int, U_ghost, normal, theta, gamma) def compute_ppr_rusanov_interface_flux(U_L, U_R, normal, theta, gamma): """ Evaluates interface normal flux using regularized pressure and safe wave speeds. """ nx, ny, nz = normal # Left State Flux & Pressure rho_L = U_L[0] u_L, v_L, w_L = U_L[1]/rho_L, U_L[2]/rho_L, U_L[3]/rho_L ke_L = 0.5 * rho_L * (u_L**2 + v_L**2 + w_L**2) Pp_L = (gamma - 1.0) * (U_L[4] - ke_L) Pr_L = Pp_L + theta * (Pp_L - U_L[5]/rho_L) un_L = u_L*nx + v_L*ny + w_L*nz Fn_L = np.array([ rho_L*un_L, U_L[1]*un_L + Pr_L*nx, U_L[2]*un_L + Pr_L*ny, U_L[3]*un_L + Pr_L*nz, (U_L[4] + Pr_L)*un_L, U_L[5]*un_L ]) # Right State Flux & Pressure rho_R = U_R[0] u_R, v_R, w_R = U_R[1]/rho_R, U_R[2]/rho_R, U_R[3]/rho_R ke_R = 0.5 * rho_R * (u_R**2 + v_R**2 + w_R**2) Pp_R = (gamma - 1.0) * (U_R[4] - ke_R) Pr_R = Pp_R + theta * (Pp_R - U_R[5]/rho_R) un_R = u_R*nx + v_R*ny + w_R*nz Fn_R = np.array([ rho_R*un_R, U_R[1]*un_R + Pr_R*nx, U_R[2]*un_R + Pr_R*ny, U_R[3]*un_R + Pr_R*nz, (U_R[4] + Pr_R)*un_R, U_R[5]*un_R ]) # Safe Speed of Sound Bounds a_L = np.sqrt(gamma * max(Pp_L, Pr_L) / rho_L) a_R = np.sqrt(gamma * max(Pp_R, Pr_R) / rho_R) lambda_max = max(abs(un_L) + a_L, abs(un_R) + a_R) # Interface Normal Flux Evaluation return 0.5 * (Fn_L + Fn_R) - 0.5 * lambda_max * (U_R - U_L)
