HLLC Flux for Phantom Pressure Regularization

Mathematical Derivation & 2D/3D Production Implementation

1. Why Upgrade from Rusanov to HLLC?

While the Rusanov (Lax-Friedrichs) flux is extremely simple and robust, its single global wave-speed signal dissipation ($\lambda_{max}$) introduces severe numerical dissipation across non-acoustic waves.

  • Excessive Boundary Layer & Contact Smearing: Rusanov treats contact discontinuities, shear layers, and boundary layers with the maximum acoustic wave speed ($|u_n| + a$). This excessively smears shear waves and boundary layers in high-order simulations.
  • Resolution of the $S^*$-Contact Wave: The HLLC (Harten-Lax-van Leer-Contact) solver explicitly restores the isolated middle contact wave ($S^*$). This ensures that entropy interfaces and contact surfaces are resolved with zero dissipation when aligned with the grid, while retaining full shock-capturing stability when coupled with PPR.
  • Exact Conservation of Passive Scalars: Because the phantom pressure state $S = \rho P_{phan}$ is passively advected with the fluid velocity, HLLC transports $S$ across contact waves without generating spurious numerical diffusion.

2. Mathematical Derivation of the PPR-HLLC Flux

The 3D compressible Euler equations augmented with the phantom pressure state vector $\mathbf{U} = [\rho, \rho u, \rho v, \rho w, E, S]^T$ have the following interface normal flux vector $\mathbf{F}_n(\mathbf{U})$:

$$\mathbf{F}_n(\mathbf{U}) = \begin{bmatrix} \rho u_n \\ \rho u u_n + P_{reg} n_x \\ \rho v u_n + P_{reg} n_y \\ \rho w u_n + P_{reg} n_z \\ (E + P_{reg}) u_n \\ S u_n \end{bmatrix}$$

where $u_n = \mathbf{u} \cdot \mathbf{n} = u n_x + v n_y + w n_z$ is the normal velocity, and $P_{reg} = P_{phys} + \theta (P_{phys} - P_{phan})$ is the regularized pressure.

Step 1: Signal Wave Speed Estimates ($S_L, S_R$)

To prevent shock-instabilities (carbuncles) while keeping acoustic safety, we estimate the left ($S_L$) and right ($S_R$) fastest wave speeds using Davis/Einfeldt bounds incorporating the maximum of physical and regularized pressures:

$$a_L = \sqrt{\gamma \frac{\max(P_{phys, L}, P_{reg, L})}{\rho_L}}, \quad a_R = \sqrt{\gamma \frac{\max(P_{phys, R}, P_{reg, R})}{\rho_R}}$$ $$S_L = \min\left(u_{n, L} - a_L, u_{n, Roe} - a_{Roe}\right), \quad S_R = \max\left(u_{n, R} + a_R, u_{n, Roe} + a_{Roe}\right)$$

Step 2: Contact Wave Speed ($S^*$) & Star Regularized Pressure ($P^*$)

By integrating the normal momentum jump condition across the star region $[S_L, S_R]$ using $P_{reg}$, the middle contact wave speed $S^*$ is determined analytically:

$$S^* = \frac{P_{reg, R} - P_{reg, L} + \rho_L u_{n, L} (S_L - u_{n, L}) - \rho_R u_{n, R} (S_R - u_{n, R})}{\rho_L (S_L - u_{n, L}) - \rho_R (S_R - u_{n, R})}$$

The regularized pressure in the star region $P^*$ is identical on both sides of the contact wave:

$$P^* = P_{reg, L} + \rho_L (S_L - u_{n, L})(S^* - u_{n, L}) = P_{reg, R} + \rho_R (S_R - u_{n, R})(S^* - u_{n, R})$$

Step 3: Modified Star States ($\mathbf{U}_L^*, \mathbf{U}_R^*$)

For $K \in \{L, R\}$, the intermediate state vector $\mathbf{U}_K^*$ in the star region is given by:

$$\mathbf{U}_K^* = \rho_K \left(\frac{S_K - u_{n, K}}{S_K - S^*}\right) \begin{bmatrix} 1 \\ u_K + (S^* - u_{n, K})n_x \\ v_K + (S^* - u_{n, K})n_y \\ w_K + (S^* - u_{n, K})n_z \\ \frac{E_K}{\rho_K} + (S^* - u_{n, K})\left(S^* + \frac{P_{reg, K}}{\rho_K (S_K - u_{n, K})}\right) \\ \frac{S_K}{\rho_K} \end{bmatrix}$$

Step 4: HLLC Flux Selection Structure

The final numerical interface flux $\mathbf{F}_{HLLC}$ is defined according to the spatial position of the four wave regions relative to the interface $x/t = 0$:

$$\mathbf{F}_{HLLC} = \begin{cases} \mathbf{F}_n(\mathbf{U}_L) & \text{if } 0 \le S_L \\ \mathbf{F}_n(\mathbf{U}_L) + S_L (\mathbf{U}_L^* - \mathbf{U}_L) & \text{if } S_L < 0 \le S^* \\ \mathbf{F}_n(\mathbf{U}_R) + S_R (\mathbf{U}_R^* - \mathbf{U}_R) & \text{if } S^* < 0 \le S_R \\ \mathbf{F}_n(\mathbf{U}_R) & \text{if } S_R < 0 \end{cases}$$
Compatibility with WE-BC: When using the Wall-Equilibrated Boundary Condition (WE-BC), setting $S^+ = 2\rho^- P_{phys}^- - S^-$ on wall boundaries ensures $P_{reg, L} = P_{reg, R} = P_{phys}^-$. The HLLC solver automatically reduces to the exact physical wall momentum reaction force without any artificial pressure jump.

3. Production Python Implementation

Below is the production-ready 2D/3D implementation of the PPR-HLLC Riemann solver. It seamlessly integrates with the Wall-Equilibrated Boundary Condition (WE-BC) framework.

import numpy as np def compute_ppr_hllc_interface_flux(U_L, U_R, normal, theta, gamma): """ Evaluates the 2D/3D HLLC numerical flux for Phantom Pressure Regularization (PPR). Parameters: ----------- U_L, U_R : ndarray shape (6,) -> [rho, rhou, rhov, rhow, E, S] (Left/Right States) normal : ndarray shape (3,) -> Unit outward normal vector [nx, ny, nz] theta : float -> PPR regularizing parameter gamma : float -> Ratio of specific heats Returns: -------- F_hllc : ndarray shape (6,) -> Numerical interface flux """ nx, ny, nz = normal # ------------------------------------------------------------------------- # 1. LEFT STATE PRIMITIVES & REGULARIZED PRESSURE # ------------------------------------------------------------------------- rho_L = U_L[0] inv_rho_L = 1.0 / rho_L u_L = U_L[1] * inv_rho_L v_L = U_L[2] * inv_rho_L w_L = U_L[3] * inv_rho_L un_L = u_L * nx + v_L * ny + w_L * nz ke_L = 0.5 * rho_L * (u_L**2 + v_L**2 + w_L**2) Pp_L = (gamma - 1.0) * (U_L[4] - ke_L) S_L_val = U_L[5] Pphan_L = S_L_val * inv_rho_L Pr_L = Pp_L + theta * (Pp_L - Pphan_L) # Physical Flux L F_L = np.array([ rho_L * un_L, U_L[1] * un_L + Pr_L * nx, U_L[2] * un_L + Pr_L * ny, U_L[3] * un_L + Pr_L * nz, (U_L[4] + Pr_L) * un_L, S_L_val * un_L ]) # ------------------------------------------------------------------------- # 2. RIGHT STATE PRIMITIVES & REGULARIZED PRESSURE # ------------------------------------------------------------------------- rho_R = U_R[0] inv_rho_R = 1.0 / rho_R u_R = U_R[1] * inv_rho_R v_R = U_R[2] * inv_rho_R w_R = U_R[3] * inv_rho_R un_R = u_R * nx + v_R * ny + w_R * nz ke_R = 0.5 * rho_R * (u_R**2 + v_R**2 + w_R**2) Pp_R = (gamma - 1.0) * (U_R[4] - ke_R) S_R_val = U_R[5] Pphan_R = S_R_val * inv_rho_R Pr_R = Pp_R + theta * (Pp_R - Pphan_R) # Physical Flux R F_R = np.array([ rho_R * un_R, U_R[1] * un_R + Pr_R * nx, U_R[2] * un_R + Pr_R * ny, U_R[3] * un_R + Pr_R * nz, (U_R[4] + Pr_R) * un_R, S_R_val * un_R ]) # ------------------------------------------------------------------------- # 3. WAVE SPEED ESTIMATION (S_L, S_R, S_star) # ------------------------------------------------------------------------- # Acoustic sound speeds using maximum of physical and regularized pressures a_L = np.sqrt(gamma * max(Pp_L, Pr_L) * inv_rho_L) a_R = np.sqrt(gamma * max(Pp_R, Pr_R) * inv_rho_R) # Roe-averaged normal velocity and sound speed sqrt_rho_L = np.sqrt(rho_L) sqrt_rho_R = np.sqrt(rho_R) inv_sqrt_sum = 1.0 / (sqrt_rho_L + sqrt_rho_R) un_roe = (sqrt_rho_L * un_L + sqrt_rho_R * un_R) * inv_sqrt_sum H_L = (U_L[4] + Pr_L) * inv_rho_L H_R = (U_R[4] + Pr_R) * inv_rho_R H_roe = (sqrt_rho_L * H_L + sqrt_rho_R * H_R) * inv_sqrt_sum ke_roe = 0.5 * ((sqrt_rho_L*u_L + sqrt_rho_R*u_R)*inv_sqrt_sum)**2 + \ 0.5 * ((sqrt_rho_L*v_L + sqrt_rho_R*v_R)*inv_sqrt_sum)**2 + \ 0.5 * ((sqrt_rho_L*w_L + sqrt_rho_R*w_R)*inv_sqrt_sum)**2 a_roe = np.sqrt(max(1e-12, (gamma - 1.0) * (H_roe - ke_roe))) # Einfeldt Bounds S_L = min(un_L - a_L, un_roe - a_roe) S_R = max(un_R + a_R, un_roe + a_roe) # Middle Contact Wave Speed S_star num_star = Pr_R - Pr_L + rho_L * un_L * (S_L - un_L) - rho_R * un_R * (S_R - un_R) den_star = rho_L * (S_L - un_L) - rho_R * (S_R - un_R) S_star = num_star / den_star # ------------------------------------------------------------------------- # 4. HLLC FLUX SELECTION LOGIC # ------------------------------------------------------------------------- if S_L >= 0.0: return F_L elif S_L < 0.0 and S_star >= 0.0: # Left Star State U_L* fac_L = rho_L * (S_L - un_L) / (S_L - S_star) U_star_L = np.array([ fac_L, fac_L * (u_L + (S_star - un_L) * nx), fac_L * (v_L + (S_star - un_L) * ny), fac_L * (w_L + (S_star - un_L) * nz), fac_L * (U_L[4]*inv_rho_L + (S_star - un_L) * (S_star + Pr_L / (rho_L * (S_L - un_L)))), S_L_val * (S_L - un_L) / (S_L - S_star) ]) return F_L + S_L * (U_star_L - U_L) elif S_star < 0.0 and S_R >= 0.0: # Right Star State U_R* fac_R = rho_R * (S_R - un_R) / (S_R - S_star) U_star_R = np.array([ fac_R, fac_R * (u_R + (S_star - un_R) * nx), fac_R * (v_R + (S_star - un_R) * ny), fac_R * (w_R + (S_star - un_R) * nz), fac_R * (U_R[4]*inv_rho_R + (S_star - un_R) * (S_star + Pr_R / (rho_R * (S_R - un_R)))), S_R_val * (S_R - un_R) / (S_R - S_star) ]) return F_R + S_R * (U_star_R - U_R) else: return F_R
