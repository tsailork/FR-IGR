◆ apply_entropy_limiter() [1/2]

Limiters::LimiterStats Limiters::apply_entropy_limiter ( Solver & solver)

Apply the entropy minimum preservation limiter to the active solver grid.

Scans each block element, identifies the local specific entropy floor s_floor, and applies the selected LIMITER_STRATEGY (ZHANG_SHU, BBCH, MODAL, HERMITE) to enforce specific entropy s = p / rho^gamma >= s_floor across solution nodes and face checking points.

Parameters
[in,out]solverThe active solver instance whose state fields will be limited.
Returns
LimiterStats containing the count of modified elements and average scaling parameter.

◆ apply_positivity_limiter() [1/2]

Limiters::LimiterStats Limiters::apply_positivity_limiter ( std::vector< Cell * > & cells,
const Basis & basis,
const Parameters & p )

Enforce positive density and pressure fields at all physical degrees of freedom.

Checks density and pressure values at both internal solution points and face-extrapolated interface points (including PPR phantom and regularized pressure when ENABLE_PPR is true). Supports 4 modular limiter strategies selected via LIMITER_STRATEGY:

  • ZHANG_SHU : Zhang & Shu (2010/2011) uniform scaling to cell average.
  • BBCH : Dumont & Loubère (2013), Dzanic & Witherden (2022) Bernstein-Bézier Convex Hull limiter.
  • MODAL : Persson & Peraire (2006), Dzanic & Witherden (2022) Scale-aware Legendre modal damping limiter.
  • HERMITE : Ciallella & Torlo (2023), Vilar (2019) Subgrid Hermite patch limiter.
Parameters
[in,out]cellsFlat vector of computational cells.
[in]basisThe high-order polynomial basis definition.
[in]pGlobal simulation parameters defining positivity floors.
Returns
LimiterStats containing the count of modified elements and average scaling parameter.
