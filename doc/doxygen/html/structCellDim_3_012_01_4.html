Detailed Description

Represents a single computational element/cell in the quadtree domain (2D).

Storage and connectivity data structure representing a single leaf node in 2D.

Encapsulates element local physical geometry, solution DOFs, residual accumulators, and IGR entropic pressure fields (\Sigma). Manages non-conforming neighbor links and Quadtree AMR refinement levels.
